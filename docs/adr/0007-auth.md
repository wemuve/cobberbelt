# ADR 0007 — Authentication: Argon2id + short-lived JWT, refresh in an httpOnly cookie

**Status:** accepted · 2026-10-20

**Decision.** Passwords are hashed with Argon2id. Access tokens are HS256 JWTs (30 min) sent as `Authorization: Bearer`, and the browser keeps them in memory only. Refresh tokens sit in an `httpOnly; SameSite=Strict; Secure` cookie scoped to `/api/v1/auth`, and `/auth/refresh` also requires an `X-Requested-With: copperbelt` header, which cross-site forms cannot send. Since bearer tokens are not ambient credentials, the rest of the API is not exposed to CSRF. Each user has a `token_version`, so `logout-all` and password changes revoke every token. Membership is checked on every request, so revoking a member takes effect immediately.

**Later.** Add OIDC/SAML SSO for enterprise customers, TOTP MFA, and email invitations once an email provider is configured.
