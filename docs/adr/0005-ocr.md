# ADR 0005 — OCR: Tesseract (eng+fra) as the baseline, managed OCR to be evaluated

**Status:** accepted for the first release; production default pending evaluation

**Decision.** Pages with at least `CBI_OCR_MIN_TEXT_CHARS` of text-layer text use it; other pages are rendered at 300 dpi with pdfium (Apache/BSD licence, chosen over AGPL MuPDF) and OCR'd with Tesseract 5. Mean word confidence is stored per page, and reprocessing with `force_ocr` is supported.

**Open.** The brief requires comparing a managed OCR service (for example AWS Textract or Google Document AI) with the open-source baseline **on real historical documents** before choosing the production default. That needs a representative set of 30–50 scanned pages (typed reports, tables, handwriting, degraded scans) with hand-checked transcriptions, scored on character error rate and table fidelity. We cannot run it until such documents are provided.
